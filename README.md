# Virtuous Loom — Portfolio v1 (Snapshot)

This is a saved snapshot of the Virtuous Loom portfolio website. Use it as a fallback if needed.

---

## How to run the preview

### 1. Open a terminal and navigate to this folder

```bash
cd path/to/v1_VL
```

### 2. Install dependencies (one-time — only needed on first run)

```bash
npm install
```

### 3. Start the dev server

```bash
npm run dev
```

### 4. Open in browser

The terminal will show a local URL — usually:

```
http://localhost:5173
```

Open that in your browser to see the website.

---

## Notes

- `node_modules` and `.git` were excluded from this snapshot to keep it lightweight.
- Always run `npm install` before `npm run dev` if `node_modules` is not present.
- This snapshot was taken from the `Portfolio-website-main` project.
